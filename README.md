# Tatu Wallet - API

Essa é a api do nosso projeto acadêmico "Tatu Wallet", ela é uma carteira cripto que tem como diferencial nada (ainda)

## Funcionalidades

- Suporte a Ethereum
- Criar/importar wallet
- Consultar saldo
- Consultar histórico
- Enviar transação simples assinada
- Favoritar uma criptomoeda
- Importar e recuperar Backup de carteiras anteriores através de chaves privadas ou seed
mnemôncia.
